# Excel_Coffee_shop_sales_project
Just finished my Excel portfolio project on Coffee Shop Sales ☕📊

(Analyzing 149k+ transactions across 6 months 👀)

Here’s what I did:

▪️ Cleaned and prepped the dataset for analysis
▪️ Created custom columns like hour, weekday, total_bill, and category
▪️ Used Pivot Tables, Power Query, and Power Pivot to break down:

 ↳ Sales by weekday
 ↳ Sales by product & category
 ↳ Hourly order volumes
 ↳ Size-based ordering behavior
 ↳ Top 5 products based on sales
 ↳ Store-wise footfall & revenue

Then I pulled it all together into a dynamic Excel dashboard:

✅ Charts
✅ Filters
✅ Interactive slicers for deep dive
